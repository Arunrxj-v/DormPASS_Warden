# DormPASS — Warden Web App

The **DormPASS Warden Web App** is the web-based management portal for hostel wardens. It allows wardens to manage students, hostels, rooms, student accounts, face enrollment, attendance, and related administrative operations from a centralized interface.

---

## Overview

DormPASS is a student residential management and attendance platform designed to simplify hostel administration and automate student attendance.

The Warden Web App provides wardens with the tools required to manage their assigned hostel and student roster.

### Main Features

- Warden authentication
- Hostel management
- Room management
- Student management
- Student account activation
- Activation email delivery
- Face enrollment
- Face verification
- Attendance management
- Audit logging
